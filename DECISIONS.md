## Architecture

- **Next.js 16** (App Router, Turbopack) with `proxy.ts` (Next 16's replacement for `middleware.ts`). TypeScript pinned to 5.x because Next's build type-check does not support TS 7 yet.
- **Demo mode.** If `NEXT_PUBLIC_SUPABASE_URL`/`ANON_KEY` are not set, the app runs on an in-memory copy of the seed with no login (a banner says so). This lets the app and the Playwright suite run with no database. With Supabase configured, every read and write goes through RLS as the signed-in user.
- **One store interface** (`lib/db/store.ts`) with memory and Supabase implementations. Pages load whole tables once per request (`react` `cache`). That is fine at internal-tool scale; switch to filtered queries if tables grow into the tens of thousands of rows.
- **Single seed source.** `/seed/*.json` → `lib/seed/build.ts` (deterministic UUIDs) feeds both the memory store and `supabase/seed.sql` (`npm run seed:sql`).
- **shadcn/ui-style components are hand-written** (`components/ui.tsx`) on Radix primitives, rather than generated by the CLI.
- **SheetJS's CDN was unreachable** from the build environment, and the npm `xlsx` package is outdated with known advisories. Imports therefore use **Papa Parse** (CSV) and **read-excel-file** (XLSX), plus **fflate** for label zips. Templates download as CSV.
- **PWA:** web manifest plus a small hand-written service worker (`public/sw.js`): network-first pages with an offline copy of the last-viewed pages, and cache-first static assets. This is used instead of next-pwa/Serwist to avoid build-plugin coupling.
- **Proposal export:** Markdown download (`/api/proposal`) plus a print-styled page; "Save as PDF" uses the browser's print dialog, so no PDF library is needed.

## Calculation choices (spec §8)

- **Input resolution order** for every play input: play override → channel terms for this principal → channel terms → channel → market defaults → workspace settings → derived (price list, pack levels, trade rules) → placeholder zero. The play page shows where each input came from.
- **Price chain:** list price = shelf ÷ (1 + t), times (1 − retailer margin) when a distributor sits between us and the retailer. The channel margin in `P_net` is the margin of our direct customer.
- **Build-back:** `S` = W + D + K + trade spend (rebate + listing per unit) + M. As a result, headroom at the target shelf price equals contribution per unit, and the two views always agree. Negative headroom lists the single-lever moves (shelf price, margins, supplier price, freight, marketing) needed to reach zero.
- **Peak cash** = steady-state landed stock + receivables − payables, with 365/12 days per month.
- **Tags:** weakest first is placeholder < estimated < public < quoted < measured < computed. Pure constants and counts are `computed`, so they never weaken a result.
- **Stale** applies only to `public`/`estimated`/`placeholder` values older than the threshold (default 180 days). Measured and quoted values are never flagged stale.
- **Market score:** if no manual Size score exists, Size is derived from population (log scale). The other factors are entered manually with a note.
- **Duty:** a preferential regime applies only when the play lists the matching certificate-of-origin form; otherwise MFN.
- **Principal P&L:** principal net sales = Σ P_net × Q. Market NPAT is approximated as Σ(C × Q − F) until an actual NPAT is entered. Profit share starts after cumulative NPAT repays the entered investment.
- **Scenarios:** greedy by return on cash; a play is included only if capital (entry + peak working capital), working capital, people and pallets all still fit. People default to 0.25 FTE per play (setting). Pallets = Q × stock days ÷ 30.4 ÷ units per pallet.
- **Costs from wizard step 6** are saved at market level, so they apply to every play in that market unless overridden.

## Explain layer (spec §7)

- `<Num>` is the only number renderer. `tests/unit/no-raw-numbers.test.ts` fails on `toFixed`, `toLocaleString`, `Intl.NumberFormat`, the format helpers, or `{x.value}` in any UI file other than `num.tsx`/`explain-card.tsx`.
- **Not counted as "numbers"** (deliberately exempt): form input values, row and month indices in tables, transient confirmation messages ("Imported 3 rows"), and the exported proposal document.
- Chart axes are hidden; every chart lists its values underneath as `<Num>`. Tapping a bar or a 3D layer opens the same explain card.
- Inline numbers keep their text size but get a 44px touch target via a pseudo-element on coarse pointers.

## Trial mode (added 26 Oct 2026)

- Trial mode runs on its own in-memory copy of the seed plus fictional sample activity (`lib/seed/trial.ts`). It never reads from or writes to Supabase.
- Entry is gated by the allowlist (`is_email_allowed`), not by a sign-in link. Anyone who knows an allowlisted email can therefore open the **sample** data (which includes the seeded Myanmar audit and partner terms) but never the live database. Set `TRIAL_MODE=off` to remove this.
- On serverless, memory is per instance, so trial edits are not durable. This is acceptable for exploring; real work belongs in the live workspace.
